# Coyote V3 BLE

Reference: <https://github.com/dungeonlab-open/dglab-bluetooth-protocol/tree/main/coyote/v3>

This directory summarizes the wire behavior used by `pulselink`. It intentionally does not reproduce
the official documentation text.

Files:

- `gatt.md` — services and characteristics;
- `b0.md` — 20-byte control command;
- `bf.md` — 7-byte settings command;
- `b1.md` — 4-byte intensity response;
- `waveform.md` — pulse interval and intensity semantics.

The official protocol documentation states that commercial use requires prior authorization from
DG-LAB.
