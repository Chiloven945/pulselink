# B0 command

20 bytes, sent every 100 ms. It contains both channels.

```text
byte 0      : 0xB0
byte 1      : sequence (4 bits) | modeA (2 bits) | modeB (2 bits)
byte 2      : channel A intensity setting
byte 3      : channel B intensity setting
bytes 4..8  : channel A pulse frequency values
bytes 8..12 : channel A pulse intensity values
bytes 12..16: channel B pulse frequency values
bytes 16..20: channel B pulse intensity values
```

Intensity modes:

| Bits   | Behavior                |
|--------|-------------------------|
| `0b00` | Keep current intensity  |
| `0b01` | Increase by the setting |
| `0b10` | Decrease by the setting |
| `0b11` | Set absolute intensity  |

Validation:

- sequence: `0..=15`;
- intensity: `0..=200`;
- wire pulse frequency: `10..=240`;
- pulse intensity: `0..=100`.

A channel's four pairs are discarded by the device if any pulse intensity is outside `0..=100`.
`pulselink` uses amplitude `101` to encode explicit silence.
